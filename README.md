# Neovim for Web Development

This project contains scripts and configuration files to install and configure Neovim for web development.

## Pre-requisites

This project installs all pre-requisites automatically (superuser credentials necessary).

## Instructions

To install Neovim and set it up for web development, run 

```
./install
```

To uninstall Neovim and remove all configuration files/directories, run

```
./uninstall
```
